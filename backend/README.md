# Material Finder AI backend

Gemma 4 26B A4B บน Cloudflare Workers AI. ไม่ใช้ Gemini API key หรือ Copilot token.

Worker เดิม: `bdms-material-gemini` (คงชื่อเพื่อใช้ URL เดิม)
URL: https://bdms-material-gemini.bdms-material-finder.workers.dev
Frontend: https://bdms-bss.github.io/material-finder/

## Configuration

- AI binding: `AI`
- AI_MODEL: `@cf/google/gemma-4-26b-a4b-it` — allowlist รุ่นที่ทดสอบแล้วเท่านั้น
- ALLOWED_ORIGIN: `https://bdms-bss.github.io`
- TURNSTILE_HOSTNAME: `bdms-bss.github.io`
- Secret: `TURNSTILE_SECRET_KEY` (เก็บใน Dashboard เท่านั้น)
- AI_RATE_LIMITER: 20 requests / 60s ต่อ IP/location ตาม wrangler.jsonc
- Public frontend config: docs/ai-config.json เก็บ URL และ public sitekey เท่านั้น

Gemini secret เดิมไม่ได้ใช้งาน ไม่ต้องสร้าง key ใหม่. ไม่เผยแพร่ secret ใน repo หรือแชต.

## API

GET `/api/health`: รายงาน configuration และ model ไม่เรียก inference และไม่ยืนยันว่าโควตายังเหลือ.
POST `/api/intent`: query, optional inline JPEG/PNG/WebP image, Turnstile token action `material-intent`.
POST `/api/rank`: query, intent, material-only candidates, fresh token action `material-rank`.

Intent → browser retrieves up to 40 candidates → rank. Model selects short references (r1/r2), never copies Material Codes. Server maps allowed references to source IDs; browser checks against candidate whitelist. Unknown refs, duplicates and excluded groups cannot become recommendations. Up to 3 distinct groups. GL/Asset/accounting classifications are read from Master, not generated by AI.

No arbitrary upstream proxy, no user-specified model and no fallback to paid providers. Request/image size bounded, candidate count bounded, token hostname/action verified, upstream timeout and sanitized errors. Cancellation may not stop inference already running.

## Deploy

Use the pinned local Wrangler and an authenticated owner account. `npm ci`, then `npm run deploy`. Keep TURNSTILE_SECRET_KEY in Cloudflare secret storage. Validate with `wrangler deploy --dry-run` first. Cloudflare API uploads must preserve existing secrets and include both worker.mjs and inference.mjs, or use Wrangler's bundle.

Main GitHub push deploys Pages `/docs`, not the Worker. Account/Worker target must be verified before deployment. Worker code deploy is reversible; do not upgrade plan, remove secrets or alter account resources without authorization.

## Free allocation and limits

Workers AI includes a daily free allocation; Free plan stops when exceeded. Paid plan can bill excess usage. Do not enable Paid or AI Gateway credit billing without owner approval. No plan upgrades were made for this change. Rate limiting is approximate/location scoped, not a global billing cap.

https://developers.cloudflare.com/workers-ai/platform/pricing/
https://developers.cloudflare.com/workers-ai/models/gemma-4-26b-a4b-it/

Logs/traces remain disabled to preserve the existing cost/data-retention settings; this limits production diagnostics. Never log query/image/secret contents if observability is later enabled.
