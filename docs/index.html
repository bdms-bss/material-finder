ใช้อินเทอร์เน็ตดาวน์โหลดโมเดลภาษา ~118 MB หรือโมเดลภาพ ~154 MB พร้อม runtime จากนั้น browser จะเก็บ cache ตามที่อุปกรณ์อนุญาต เครื่องที่หน่วยความจำน้อยอาจใช้เวลานาน

เริ่มใช้งาน Material Master

  1. ค้นหาด้วยสิ่งที่คุณรู้

    ใช้ชื่อสินค้า ภาษาไทยหรืออังกฤษ รหัส Material หรือ Material group ก็ได้ หากมีเพียงภาพ ให้เลือก “ค้นหาจากรูปภาพ”

  2. เลือกและตรวจข้อมูล

    ดูหมวด L0 และประเภทค่าใช้จ่าย แล้วเปิดรายละเอียดเพื่อตรวจ Group, GL ตาม Department และ Asset class

  3. ตรวจ Catalog ของ Plant ก่อนใช้

    Material code เป็นรหัสใน Master ส่วน Material group เป็นกลุ่มสินค้า ข้อมูลนี้ไม่มีรายการ Catalog ที่แยกตาม Plant จึงต้องตรวจสอบ Catalog ของ Plant ก่อนนำรหัสไปใช้เปิด PR

ขอบเขตข้อมูล

Catalog แยกรายการตาม Plant และมีจำนวนรายการมาก ระบบนี้จึงแสดงเฉพาะ Material Master ส่วนกลาง ไม่ได้แสดงหรือยืนยันความพร้อมของ Catalog ใน Plant

อ้างอิง Excel snapshot 30 ต.ค. 2026 โดยวันที่ปรับปรุงแต่ละ sheet อาจต่างกัน ตัด Deletion X, INACTIVE, (CANCEL), Group Z00000000 และ M* ก่อนเว็บโหลดข้อมูล · Group Z* ที่เหลือเป็น Direct Pay โดยไม่ได้เติมเป็น L0 ใน Taxonomy

CAPEX = มี Asset class · OPEX = มี GL-A/GL-C · มีทั้งสอง mapping = CAPEX/OPEX
