# BDMS logo

Unmodified vector version of the BDMS red/blue wordmark and “Bangkok Dusit Medical Services” caption, matching the logo reference supplied for this application.

- Source: https://commons.wikimedia.org/wiki/File:Bangkok_Dusit_Medical_Services_Logo.svg
- Original vector: https://upload.wikimedia.org/wikipedia/commons/4/4e/Bangkok_Dusit_Medical_Services_Logo.svg
- Logo author: Bangkok Dusit Medical Services
- Source references the BDMS 2024 One Report. Wikimedia marks the vector PD-textlogo with trademark notice.

The artwork has not been recolored or cropped; CSS scales it proportionally. The application theme uses the source blue `#0872b9` and red `#ea2227`, with darker blue for readable interactive text.
